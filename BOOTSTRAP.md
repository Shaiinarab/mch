# BOOTSTRAP.md

Run this once on the very first session, then archive or delete it.

1. Read PROMPT.md and use it as the first message of this session.
2. Install the harness using the route the boot prompt picks (clone / skills install / raw fetch / human upload).
3. After boot reports BOOT OK or BOOT PARTIAL, open USER.md and fill in the real profile blanks (privacy-safe only).
4. If you want extra skills, install them from ClawHub or trusted sources; do not bundle them into this repo by default.

After first use, this file can be removed. The owning repo remains the source of truth.
